# Minecraft Mods Localizer v3.0.3

## 修正内容

- Windowsの自動更新で、EXEからインストールした場合はEXE、MSIの場合はMSIを使用するよう修正しました。
- 更新のダウンロード進捗を累計で表示します。
- 更新後に再起動を後回しにした場合も、更新画面が「インストール中」のままにならないよう修正しました。
- 更新処理中にダイアログを閉じて進捗を見失うことを防ぎます。

[使い方](https://github.com/Y-RyuZU/MinecraftModsLocalizer/blob/main/docs/ja/getting-started.md) · [不具合・要望](https://github.com/Y-RyuZU/MinecraftModsLocalizer/issues)

## Fixes

- Preserve the Windows installer format during automatic updates: NSIS installations receive EXE updates, and MSI installations receive MSI updates.
- Display cumulative download progress.
- Clear the installation state when restarting is postponed.
- Keep the update dialog open while an update is running.
