# Minecraft Mods Localizer v3.0.2

## 更新内容

- クエストもModsと同じ「再翻訳する」チェックボックスで訳し直せるようになりました。既存訳は通常保持され、チェックした対象・言語だけ置き換えます。
- 翻訳する対象が2個以上、または翻訳文が100件以上の場合、初回はバッチ翻訳を選択します。翻訳開始前の確認画面で通常翻訳にも切り替えられます。前回選んだ方式がある場合は、その選択を引き継ぎます。
- 既存訳がある場合の案内を改善し、再翻訳を選択した後も「スキップ」と表示される不具合を修正しました。

[日本語の使い方](https://github.com/Y-RyuZU/MinecraftModsLocalizer/blob/main/docs/ja/getting-started.md) · [不具合・要望](https://github.com/Y-RyuZU/MinecraftModsLocalizer/issues)

## Changes

- Use the same retranslation control for quests and Mods. Existing translations are preserved unless explicitly selected for replacement in the chosen language.
- Initially select Batch for two or more translation targets, or at least 100 text entries. Switch modes before starting; previous choices are remembered.
- Clarify the existing-translation message and stop showing “skipped” after retranslation is selected.

[English guide](https://github.com/Y-RyuZU/MinecraftModsLocalizer/blob/main/docs/getting-started.md)
