# Minecraft Mods Localizer v3.0.0

Translate Minecraft mod language files, quests, and Patchouli guidebooks with your own AI provider account. Choose what to translate, review the workload, and follow the completion screen to read it in Minecraft.

## Changes

- Desktop interface with Mods, Quests, Guidebooks, and Custom Files tabs.
- OpenAI, Anthropic, and Google Gemini provider configuration.
- Legacy `.lang` language-file support and support for additional FTB Quests layouts.
- Ten interface languages. The additional eight locales are machine-translated and welcome corrections; game translation language is selected separately.
- Default interface language follows OS preferences until you choose a language. Windows NSIS bundles ten installer languages and selects the OS language.
- Localized scan status, table labels, errors, and accessibility labels across all ten locales.
- Preserve provider keys and settings through native saves; apply changed credentials immediately and migrate retired default models when using standard endpoints.
- Choose Batch or standard API before translation; large workloads recommend Batch and remember your choice per provider.
- Progress stages, Minecraft loading guidance, and output-folder shortcuts.
- Confirmation before closing the app during translation.
- Progress logs, cancellation, translation history, and backup controls.
- Tauri updater bundles with signature verification.

## Before translating

Back up your game instance. Start with one small mod and verify the generated resource pack in Minecraft before selecting a whole pack. API usage is billed separately by your provider. The desktop app stores API keys in the OS credential store and clears keys from `config.json` when settings are saved.

Choose a model currently available to your provider account. Saving settings does not validate the API key. BetterQuest fixed-name defaults are backed up and updated in place; Create: Astral language files are discovered and written to the target locale. See the first translation guide. Successful export alone does not prove the game loaded the translation.

Batch jobs can resume result retrieval after restarting the app, using the saved selection and provider job ID. Keep source files unchanged. An unknown submission outcome stops recovery to avoid duplicate submission; check the provider dashboard. Closing the app does not guarantee cancellation of submitted requests or prevent provider charges.

## Upgrading from v2

Download the v3 installer for your OS and CPU and keep a backup of your instance and old settings. Automatic migration from the older v2.1.3 executable has not been verified. Set up your provider in v3 and confirm one small translation before processing more files.

## 日本語

英語のクエストやModの説明書を、日本語などの好きな言語で読めるようにできます。自分のAPIキーを設定し、翻訳したい対象のタブを選び、まず1件でゲーム内表示を確認してください。Modの翻訳では、出力したリソースパックの有効化が必要です。

API利用料は各プロバイダー側で発生します。ゲームのインスタンスをバックアップし、APIキーを含む`config.json`は共有しないでください。v2.1.3からの自動移行は未検証のため、OSとCPUに合ったインストーラーから導入してください。詳しい操作・対応上の注意は[日本語ガイド](https://github.com/Y-RyuZU/MinecraftModsLocalizer/blob/main/docs/ja/getting-started.md)を参照してください。
