# ATM10SKY・Create: Astralの確認手順

2026年10月1日再確認。過去セッションではATM10 SKYへ実翻訳・適用済みで、Minecraftのリソースパック読み込み記録があります。ユーザー提供画像でもクエストとガイドブックの日本語表示が確認できます。以下の入力解析記録は追加の形式検証であり、実翻訳が未実施という意味ではありません。

## ATM10SKY

Prismでインスタンスのフォルダーを開き、`minecraft`をMMLの対象フォルダーにします。クエストの英語入力は`config/ftbquests/quests/lang/en_us.snbt`です。このインスタンスでは`ftb_quests`ではなく`ftbquests`でした。

コピーした入力の6,103エントリーを解析し、書き出して再解析しても内容が一致しました。日本語の出力先は同じ`lang`フォルダーの`ja_jp.snbt`です。実際に翻訳する際はインスタンスをバックアップし、少量から始め、Minecraftの言語を日本語にしてクエスト画面を確認してください。

## Create: Astral

確認したMinecraft 1.18.2のインスタンスでは、Load My Resourcesの設定が`resources/`を読み込みます。

1. インスタンスをバックアップします。
2. **クエスト**タブで`minecraft`フォルダーを選び、スキャンします。
3. `resources/createastral/lang/en_us.json`を選び、日本語へ翻訳します。
4. 出力は同じフォルダーの`ja_jp.json`です。カスタムファイル経由の手動コピーは通常不要です。
5. Minecraftの言語を日本語にし、再起動してクエストを確認します。

2,934文字列の入力解析とパス規則、探索と出力の回帰テストを確認しています。Create: Astralのゲーム画面での最終確認は別途必要です。

## 実APIの記録の区別

過去のATM10 SKYの実翻訳・適用成功と、以下のGeminiでの失敗は別の検証です。Geminiの失敗を理由に、全プロバイダーの実翻訳を未成功と扱わないでください。

### このセッションの初期Gemini確認

指定の1Password項目をCLIから読み取り、Geminiへ2文字列を1回だけ送信しました。HTTP 402で終了したため、翻訳結果は生成されていません。追加リクエストは行っていません。キーは検証用ファイルやログへ保存していません。
